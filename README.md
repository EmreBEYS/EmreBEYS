### 🗄️ YEKDB — Main Project

> A relational database management system developed from scratch in Java.

```text
YEKDB
├── Physical Storage Engine
├── Page Management
├── Record Management
├── Database Management
├── Table Management
├── Index Management
├── Query Execution
├── SQL SELECT / WHERE
└── Future
    ├── Transactions
    ├── Client / Server
    └── Query Optimization
```
